# Sicurezza e privacy

- Dati locali per default; servizi esterni solo opt-in con spiegazione di destinazione, dati inviati, scopo e costo.
- Non registrare credenziali o dati personali non necessari.
- Minimizzare retention di screenshot/video.
- Validare input e configurazioni.
- Prevedere stop, limiti durata/azioni/runtime, timeout, retry limitati e rilascio input.
- Fermarsi se ambiente ambiguo o osservazioni stale.
- Rispettare regole e termini; niente bypass anti-cheat o manipolazione non autorizzata.
- Controllare licenze e provenienza delle dipendenze e dei modelli.
