# Domande aperte

## Bloccanti
1. Primo ambiente: toy, API ufficiale o gioco desktop con interfacce consentite?
2. Sistema operativo target?
3. Hardware disponibile: CPU, RAM, GPU/VRAM e budget?
4. Primo task misurabile, successo e reset?
5. Quale tipo di interazione è consentito dal gioco/piattaforma?

## Da decidere dopo il prototipo
6. Modelli locali, cloud opt-in o nessun modello generativo iniziale?
7. Quali dati persistono: log, stime controlli, pesi?
8. CLI iniziale o UI diversa?
9. Gli obiettivi vengono forniti dall'utente o inferiti?
10. Limiti di runtime, numero azioni e autonomia non supervisionata?

## Default provvisori
Python, architettura ibrida, ambiente controllato, CLI, baseline deterministica, dati locali, contratti versionati e test. Non sono verità immutabili: registrarne le modifiche.
