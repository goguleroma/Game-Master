# Definition of Done

- [ ] Risultato atteso collegato a requisito o issue.
- [ ] Implementazione integrata nel flusso reale.
- [ ] Interfacce ed errori espliciti.
- [ ] Test normali e casi limite aggiunti.
- [ ] Controlli realmente eseguiti e risultati registrati.
- [ ] Nessuna dipendenza superflua.
- [ ] Stop, timeout e cleanup considerati.
- [ ] Log senza segreti.
- [ ] Documentazione aggiornata.
- [ ] Roadmap/stato aggiornati sulla base di prove.
- [ ] Limiti noti e recovery documentati.
