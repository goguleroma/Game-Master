# Contribuire

1. Leggere `AGENTS.md` e la documentazione pertinente.
2. Definire problema e risultato osservabile.
3. Implementare la modifica minima coerente.
4. Aggiungere o aggiornare test.
5. Eseguire i controlli e riportare i risultati reali.
6. Aggiornare la documentazione interessata.

Evitare refactor estranei e dipendenze superflue. Tenere le integrazioni specifiche dei giochi dietro adapter. Non committare credenziali o dati privati. Le pull request descrivono problema, soluzione, decisioni, test, limiti e follow-up.
